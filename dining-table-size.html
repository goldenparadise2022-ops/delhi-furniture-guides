Dining Table Size Guide

Plan for both diners and movement. A comfortable setting usually allows around 60 cm of table edge per person.

Table sizeComfortable seatingTypical use
120 × 75 cm4 peopleCompact dining nook
150 × 90 cm4–6 peopleEveryday family dining
180 × 90 cm6–8 peopleLarger dining room

Check the room

Allow about 90 cm behind occupied chairs for comfortable movement; more is helpful near a wall or serving path. Measure doorways and lifts, and consider an extendable table if you host occasionally.

Shape and base

Round tables improve conversation and soften tight rooms. Rectangular tables suit longer spaces. A pedestal base can provide more legroom than four corner legs, but check stability and chair clearance.
